Первый запуск. 
Кэша нет, показывается индикатор загрузки и грузятся первые 10 постов. Они сохраняются в кэш.

Повторное открытие. 
Сразу видны сохранённые посты с плашкой «Показаны сохранённые данные», сверху бежит полоска загрузки. После ответа сервера список и кэш обновляются.

Нет интернета. 
Кэшированные посты остаются на экране, сверху плашка «Нет подключения… Показаны сохранённые данные». Если кэша нет, показывается ошибка с кнопкой «Повторить».

Pull-to-refresh тянет данные заново, а при ошибке кэш не стирается.

Optimistic UI.
 После «Отправить» форма закрывается, пост сразу виден в списке с пометкой «отправляется…». При успехе открывается диалог с объектом от сервера (id 101), и пост остаётся с пометкой «создан локально». При ошибке пост пропадает из списка и показывается SnackBar. Повторное нажатие заблокировано флагом _submitted.
